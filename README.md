# Меню Garber — справочник рецептур

Статический сайт для кухни: поиск по блюдам и ингредиентам, разделы, пересчёт количества, печать и исходные фотографии. Сейчас внесено 6 рецептур с 2 страниц.

## GitHub Pages

В репозитории откройте **Settings → Pages**. В **Build and deployment** выберите **Deploy from a branch**, ветку **main**, папку **/ (root)** и нажмите **Save**. Адрес после успешной публикации: `https://biakib.github.io/menu_Garber/`.

Все пути относительные, поэтому сайт работает в подпапке репозитория. Сборка для публикации не требуется.

## Локальный запуск

Откройте терминал в папке проекта и выполните:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Для проверки и обновления начальной карточки нужен Node.js:

```sh
node scripts/check.cjs
node scripts/build.cjs
```

## Файлы

- `index.html` — структура и первая карточка, видимая до запуска скриптов.
- `styles.css` — версии для компьютера, планшета и телефона.
- `app.js` — поиск, фильтры, выбор рецептуры, пересчёт и печать.
- `data/recipes.js` — все данные блюд; единственный источник рецептур.
- `source.jpeg`, `source-02.jpeg` — исходные фотографии.
- `scripts/build.cjs` — обновление начального содержимого HTML после правки данных.
- `scripts/check.cjs` — проверка данных и поиска.

## Добавление рецептуры

Добавьте объект в массив `recipes` в `data/recipes.js`. Поля: уникальный `id`, `title`, `category`, `subtitle`, `batch`, `output`, `note`, `pages`, `ingredients`, `steps`. Ингредиент задаётся как `["Название", граммы]`, допустим третий элемент с примечанием. Неясные значения сохраняйте с пояснением в `note`, не исправляйте по догадке.

Для новых фотографий расширьте сопоставление номера страницы и имени изображения в `app.js`. При появлении нового раздела добавьте кнопку фильтра в `index.html`. Выполните проверку и сборку и сохраните изменения в GitHub.

## Проверка перед сдачей

Логика поиска и пересчёта проверена программно. Визуальная проверка текущей версии в браузерах ещё требуется: проверьте ширины 320, 390, 768, 1024 и 1440 пикселей, поиск, выбор всех блюд, увеличение текста и раскрытие фотографий.

Спорные выходы блюд отмечены в карточках. Подтверждение рецептур и выходов выполняет кухня.
